# NEA Motos (Corrientes)

NEA Motos es una página pensada para un negocio dedicado a la venta y asesoramiento de motos y productos relacionados en **Corrientes (Argentina)**. La experiencia está enfocada en que los visitantes puedan explorar lo que ofrecemos y, cuando lo necesiten, realizar consultas rápidas desde la propia web.

La web incluye secciones con información y catálogos para:
- **Motos** (catálogo general)
- **Motos usadas** (motos disponibles con fotos y datos)
- **Cascos** (protección y asesoramiento)
- **Cubiertas** (opciones y consulta)
- **Indumentaria** (productos para cada viaje)
- **Financiación** (consulta por planes)
- **Seguros** (protección para tu moto)

Además, la página contempla recursos para inspirar la elección, como galerías, destacados y reseñas, y ofrece una comunicación directa mediante **WhatsApp** para responder dudas sobre disponibilidad, precio y características.

Esta es una web realizada para acompañar el día a día del negocio, mejorar la visibilidad y facilitar el contacto con clientes en la zona y más allá.
